Connect **Aider** terminal pair programming assistant with Cephalo.

## 1. Quick Start

Run Aider with Cephalo context:

```bash
aider --read "C:\Users\strider-desktop\.gemini\antigravity\scratch\second-brain\USER_PROFILE.md"
```

Aider will immediately ground its pair programming in your hardware profiles, anti-slop rules, and language preferences.
